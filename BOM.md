# Bill of Materials

Everything you need to build one LUMA. Prices are rough, in CAD, and depend on where you
buy and how much shipping hurts. A full build is around $20-25.

| Part | Qty | Approx cost (CAD) |
|---|---|---|
| ESP32 Dev Board (WROOM-32) | 1 | ~$5 |
| DIYmalls 1.8" ST7735S TFT LCD | 1 | ~$4 |
| TTP223 capacitive touch sensor | 2 | ~$1 each |
| Breadboard | 1 | ~$3 |
| Dupont jumper wires | 1 set | ~$2 |
| USB-C cable + adapter | 1 | ~$3 |
| ESP32 breakout board | 1 | ~$3 (optional but makes wiring the 3V3/GND rails way easier) |

**Total: roughly $20-25 CAD**

You'll also need filament for the printed enclosure (a couple dollars) and a free
OpenWeatherMap API key for the weather screen.

Full parts list with buy links, wiring, and the rest of the build guide is at
[meetluma.live](https://www.meetluma.live/).
