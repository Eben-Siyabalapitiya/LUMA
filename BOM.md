# Bill of Materials

Machine-readable version with links: [`BOM.csv`](BOM.csv).

Prices are what I actually see on Amazon.ca (Aug 2026), in CAD, before tax and shipping.
They move around a lot and everything is cheaper on AliExpress if you're willing to wait.

| Part | Qty | Amazon.ca price (CAD) |
|---|---|---|
| ESP32 dev board, WROOM-32, 30-pin, USB-C | 1 | ~$14 |
| DIYmalls 1.8" ST7735S TFT LCD (128x160 SPI) | 1 | ~$15 single, ~$21 for a 2-pack |
| TTP223 capacitive touch sensor | 2 | only sold in packs, ~$13 for 20 |
| 830-point solderless breadboard | 1 | ~$8 single, ~$13 for a 3-pack |
| Dupont jumper wires, 120 pcs (M-M / M-F / F-F) | 1 kit | ~$9 |
| USB-C data cable | 1 | ~$8 |
| ESP32 30-pin breakout board (optional, expands 1 GPIO to 2, easier than a breadboard) | 1 | ~$10, sold ~$19 for a 2-pack |

Rough totals:

- Core electronics (ESP32 + screen + touch sensors): **~$42-45**
- Add breadboard, jumper wires and a USB-C cable: **~$65-70**
- Most of the extras (breadboard, wires, cable) you probably already have.

You'll also need a bit of filament for the printed case and a free OpenWeatherMap API key.

Full parts list with links and the rest of the build guide: [meetluma.live](https://www.meetluma.live/).
