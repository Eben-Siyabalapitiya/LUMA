# CAD

The LUMA enclosure was designed in Onshape.

## STEP files (the CAD model)

Exported from Onshape.

- `LUMA_ASSEMBLY.step` : the whole thing assembled
- `Brain.step` : main body that holds the ESP32 and screen
- `Top_cover.step` : lid
- `Legs.step` : the legs
- `Leg_Joint.step` : pin that joins the legs to the body
- `Feet.step` : the feet

## Print file

- `LUMA_V3.3mf` : print-ready, opens in Bambu Studio, PrusaSlicer or Cura with the plate and
  settings already set up. Single colour, no supports needed on the body.
