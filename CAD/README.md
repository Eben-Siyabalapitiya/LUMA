# CAD

The LUMA enclosure was designed in Onshape.

- **`LUMA_V3.3mf`** : print-ready file for the whole enclosure. Opens in Bambu Studio,
  PrusaSlicer or Cura with the plate and print settings already set up. Single colour,
  no supports needed on the body.
- **Onshape (live CAD):** <https://cad.onshape.com/documents/46f7879e5381e394e69948ae/w/efe1e75b1016428808b3d0a2/e/479ee3b72502e2ef5b15629c>
  Public document, so you can view it or make your own copy and change the fit, the screen
  cutout, the base size, whatever, then export a fresh 3MF or STL.

Same files and the full print/assembly walkthrough are on [meetluma.live](https://www.meetluma.live/build).
