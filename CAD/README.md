# CAD

The LUMA enclosure was designed in Onshape. You can view it, copy it, and download it
through the link on [meetluma.live](https://www.meetluma.live/).

Print files are 3MF, ready to go for Bambu Lab slicers with the print settings already set
up. Import, slice, print.

The Onshape model is parametric, so if you want to change the fit, the screen cutout, the
base size, whatever, make your own copy from the link on the website and export a new 3MF
or STL.
